## Public surface

| Method | Path |
| --- | --- |
| `POST` | `/v1/homology` |
| `POST` | `/v1/homology/batch` |
| `GET` | `/v1/homology/databases` |
| `GET` | `/v1/homology/databases/{database_id}/releases` |

These endpoint pages and the public SDKs are generated from the same curated
OpenAPI document.

## Authentication

Send an API key as a bearer token:

```bash
curl https://api.rafflesia.ai/v1/homology/databases \
  -H "Authorization: Bearer $RAFFLESIA_API_KEY"
```

Create keys in the [dashboard](https://dashboard.rafflesia.ai).

## Responses

Search responses are plain JSON objects. A single query returns `results`; a
batch returns `responses` in input order. Both include `request_id`, `usage`,
`performance`, `result_sha256`, and `warnings`.

The two list operations return `data`, `has_more`, and an opaque `next_cursor`
when another page exists.

Successful responses include:

| Header | Meaning |
| --- | --- |
| `X-Request-ID` | The request identifier. |
| `Rafflesia-API-Version` | The public API version. |
| `Rafflesia-Contract-Digest` | The served contract digest. |

Both `POST /v1/homology` and `POST /v1/homology/batch` accept an optional
`Idempotency-Key` for safe retries. List operations accept `limit`,
`starting_after`, and `ending_before`.

See [Errors](/errors) for unsuccessful responses.
