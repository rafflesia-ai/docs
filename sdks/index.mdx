title: SDKs
description: Generated clients for the public Rafflesia API.
---

Every SDK is generated from the same curated OpenAPI document as the
[API reference](/api-reference/introduction).

| Language | Package or install |
| --- | --- |
| TypeScript / Node | `npm install @rafflesia/node` |
| Python | `pip install rafflesia-sdk` |
| Go | `go get github.com/rafflesia-ai/rafflesia-go` |
| Rust | `cargo add rafflesia` |
| Java | `ai.rafflesia:rafflesia` |
| .NET | `dotnet add package Rafflesia` |
| Ruby | `gem install rafflesia` |
| PHP | `composer require rafflesia/rafflesia` |

Method names follow each language's conventions. The endpoint pages own the
request and response schemas.

## Example

```ts
import { Rafflesia } from "@rafflesia/node";

const apiKey = process.env.RAFFLESIA_API_KEY;
if (!apiKey) throw new Error("RAFFLESIA_API_KEY is not set");

const client = new Rafflesia({
  apiKey,
});

const result = await client.homology({
  query: {
    kind: "protein_sequence",
    sequence: "MTEYKLVVVGAGGVGKSALTIQLIQNHFVDEYDPTIEDSYRKQV",
  },
  database: "tomato",
  limit: 10,
});
```
