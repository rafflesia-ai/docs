Rafflesia answers biological evidence questions with small, typed, reproducible
primitives. Ask for a sequence record, a pocket, a confidence summary, a
homology search, or a release-pinned SQL result, and you get back measurements
with provenance — never an interpretation, a bundled report, or hidden
reasoning.

Every response carries the exact releases, digests, and engine versions that
produced it, so the same call made twice returns the same answer, and any answer
can be traced to the bytes it came from.

## What Rafflesia will not do

The product boundary is deliberate and worth knowing before you build on it:

- **No interpretation.** A primitive returns measurements, not conclusions about
  whether two proteins are homologous or whether a variant is pathogenic.
- **No bundles or reports.** Composition is the caller's job, which keeps every
  step auditable.
- **No hidden reasoning.** There is no model in the request path deciding what
  you meant.
- **No silent fallbacks.** A missing input, an unmapped identifier, or an
  unauthorized join fails loudly instead of returning a plausible-looking
  answer.
