---
title: Command surface
description: The canonical rafflesia CLI command tree.
---

The canonical CLI exposes the curated public surface:

```text
rafflesia auth login
rafflesia auth refresh
rafflesia auth verify
rafflesia auth status
rafflesia auth logout

rafflesia homology create
rafflesia homology get
rafflesia homology results
```

Use built-in help for the exact flags in the installed binary:

```bash
rafflesia --help
rafflesia homology create --help
```

Create a retained homology search:

```bash
rafflesia homology create \
  --sequence MTEYKLVVVGAGGVGKSALTIQLIQNHFVDEYDPTIEDSYRKQV \
  --database-release-id release_123 \
  --evidence candidate_measurement \
  --max-results 50
```

Inspect it and page its immutable result evidence:

```bash
rafflesia homology get hsrch_123 --json
rafflesia homology results hsrch_123 --limit 100
```

The CLI does not contain server-internal operator, dataset, query, or biological
reasoning commands. New commands start as routes in the curated public OpenAPI
contract and use the generated SDK types.
