---
title: CLI overview
description: Install and use the canonical rafflesia CLI for the curated public API.
---

`rafflesia` is the command-line client for the public Rafflesia API. It is a
thin host over the generated Go SDK, so its request and response types come from
the same curated OpenAPI contract as the other public SDKs.

```bash
curl -fsSL https://rafflesia.ai/install.sh | sh
rafflesia --help
```

## Global flags

| Flag | Purpose |
| --- | --- |
| `--server <url>` | Override the API base URL. |
| `--api-key <key>` | Override the stored key and `RAFFLESIA_API_KEY`. |
| `--access-token <token>` | Override the stored OAuth token and `RAFFLESIA_ACCESS_TOKEN`. |
| `--json` | Print the raw response envelope. |

Credential precedence is command flag, environment variable, then the value
stored by `rafflesia auth login`. Access tokens take precedence over API keys
at the environment layer. Supplying both credential flags is an error. Without
a server override, the CLI uses `https://api.rafflesia.ai`.

## Environment variables

| Variable | Effect |
| --- | --- |
| `RAFFLESIA_API_BASE_URL` | API base URL when `--server` is absent. |
| `RAFFLESIA_API_KEY` | API key when `--api-key` is absent. |
| `RAFFLESIA_ACCESS_TOKEN` | Bearer access token when `--access-token` is absent. |
| `RAFFLESIA_CONFIG_PATH` | Exact credential-file path for isolated automation. |

## Output and exit status

Homology creation and retrieval print a compact id/status line by default.
Homology results and every command invoked with `--json` print the generated
SDK response envelope as JSON.

The CLI exits `0` on success and `1` for flag validation, transport, or API
errors.
