---
title: Quickstart
description: Run one protein homology search.
---

Create an API key in the [dashboard](https://dashboard.rafflesia.ai):

```bash
export RAFFLESIA_API_KEY=sk_production_…
```

Then run a search:

```bash
curl https://api.rafflesia.ai/v1/homology \
  -H "Authorization: Bearer $RAFFLESIA_API_KEY" \
  -H "Rafflesia-API-Version: 2026-08-08" \
  -H "Content-Type: application/json" \
  -d '{
    "query": {
      "kind": "protein_sequence",
      "sequence": "MTEYKLVVVGAGGVGKSALTIQLIQNHFVDEYDPTIEDSYRKQV"
    },
    "database": "cath-full-domains",
    "limit": 10
  }'
```

The completed search is returned immediately. An abridged response looks like:

```json
{
  "request_id": "req_…",
  "database": {
    "id": "hdb_cath_full_domains",
    "release_id": "dbr_…"
  },
  "candidates": [
    {
      "rank": 1,
      "target": { "id": "target_…" },
      "measurements": {
        "maxsim": { "bidirectional": 0.82 }
      }
    }
  ],
  "warnings": []
}
```

See [Homology search](/homology-search) to pin a release, submit a batch, or
choose additional measurements. The [API reference](/api-reference/introduction)
defines every field.
